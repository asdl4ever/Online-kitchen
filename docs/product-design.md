# 产品设计文档

> 版本 0.1(草案)。整体方向 + 主要功能梳理,细节随开发迭代补充。

## 1. 一句话定位

**上帝视角的休闲沙盒点餐游戏**:玩家是一个球,在大地图上砍树卖木材赚钱,去餐厅点餐、入座、享用美食;远期支持玩家开店与 2-4 人联机。

## 2. 玩法基调

- **纯休闲沙盒**:无时间限制、无失败/惩罚状态,自由探索、赚钱、吃饭。
- **循环**:砍树 → 卖木材赚钱 → 餐厅/手机点餐 → 入座享用 → (远期)开店赚钱。
- 目标不强推,靠"吃个爽"与轻量收集/成带来乐趣。

## 3. 技术方向(已定)

| 项 | 选择 |
|---|---|
| 平台 | 网页浏览器,即点即玩 |
| 客户端 | Phaser 3(2D)+ TypeScript |
| 服务端 | Node.js + WebSocket 权威服务器 |
| 联机形态 | host 建房 + 房间码加入,2-4 人;游戏规则由服务器裁决 |
| 美术 | 简洁几何风:圆形玩家 + 色块建筑 + 贴图树;可使用 emoji 丰富表现 |

## 4. 世界观与地图

- 单个大地图,上帝视角,相机跟随玩家,有边界。
- 区域(初期):出生广场、树林、木材店、餐厅、手机店。
- 角色:玩家为球(联机时按颜色/名字区分);餐厅有 NPC 老板/服务员;其余 NPC 后期补充。

## 5. 核心系统与操作

### 5.1 移动与操作
- WASD 移动;上帝视角相机跟随。
- 砍树:**按住鼠标左键**(面向/距离判定最近树,带进度)。
- 背包:**E** 打开/关闭(格数列表 UI,展示木材等持有物)。
- 交互:**F**(靠近柜台问老板、买木材、入座等)。
- 设置菜单:**Esc** 呼出。

### 5.2 砍树与卖木材
- 树有耐久,按住左键持续砍,砍完掉木材入包,树变树桩后按时间重生。
- 木材店:靠近交互,把背包木材按单价换成钱;HUD 显示木材/金钱。

### 5.3 餐厅点餐(核心玩法)
流程分层,逐步开放:

1. **柜台点单(默认)**:到餐台前按 F 问老板 → 弹出菜单 → 选菜付钱 → 下单。
2. **入座与上菜**:点单后到空桌按 F 入座;**服务员端着菜上桌**,玩家吃下获得"爽"感演出。
3. **手机点单(解锁)**:在手机店花钱买手机后,可在店外直接 App 下单,无需跑柜台;订单同样送达到你入座的桌。
- 出菜需要短暂等待时间(几秒),配得上"手机下单 → 入座等餐 → 上桌"的仪式感。
- 吃的反馈:"爽感"演出(满足动画/音效)+ 轻量**美食收藏**记录,无饱腹惩罚。

### 5.4 背包
- 初始少量格位,存放木材等;后续可扩展更多可持物品。

### 5.5 设置
- **声音设置**:主音量 / BGM / 音效 三条滑块。
- **按键设置**:键位表 UI,点击某项 → 按新键 → 保存;含冲突检测与恢复默认。

### 5.6 手机店
- 出售手机;购买后解锁远程点餐 App 入口(店内外均可)。

## 6. 远期方向(本版不做)

- **开店经营**:玩家自己开餐厅,服务其他玩家/NPC 顾客。
- **2-4 人联机**:同房间可见他人在线移动、共享同一片世界状态(权威服务器裁决)。
- 多区域地图、更多 NPC/商品、食物评分/成就。

## 7. 里程碑规划

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M0 | 工程骨架:Vite + Phaser3 + Node 服务端 + 房间码进出(可单机运行) | 能启动进游戏,地图可逛 |
| M1 | 移动/砍树/背包/卖木材/柜台点单/入座上菜/美食收藏/设置(音效+改键) | 单机闭环:砍树赚钱 → 点餐入座吃爽 |
| M2 | 手机店与手机点单;操作与表现打磨 | 双通道点餐跑通 |
| M3 | 2-4 人联机(权威服务器共享世界/移动同步) | 多人同图可见、协作或各自赚钱吃饭 |
| 远期 | 开店经营、成就收集、扩展区域 | 形成可持续经营沙盒 |
